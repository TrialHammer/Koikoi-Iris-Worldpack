# Koikoi 地图设计说明

Koikoi 是基于 Iris `Overworld V4005` 包制作的活动地形包，适用于 Minecraft 26.3。活动世界种子固定为 `864242790704001629`，作者地图布局种子为 `3560224932`，预览世界为 `iris:koikoi_preview`。

本包的设计目标是以原版斑驳森林为活动核心，同时保留 Iris Overworld 的大尺度地形起伏、幻想风格群系、洞穴、水文、装饰、矿物和原版结构兼容性。核心区域采用显式图片地图控制，外围继续使用 Iris 的区域、群系和噪声地形生成。

## 活动区域与图片地图

活动区域的图片源位于 `images/activity/`，对应定义位于 `image-maps/activity/`。图片以每像素一格采样，源图中心 `(512,512)` 对应世界 `(0,0)`，作者范围为 `1025×1025`。

- `terrain-mask`：控制自定义地形高度场的影响范围，并在边缘回退到 Iris 原生地形。
- `lake-height`：以双线性灰度高度图控制湖泊、湖岸和活动区周边的连续高度。
- `forest-region`：将核心区域映射到 `dappled` Iris 区域。
- `surface-biomes`：将湖泊、湖岸、核心森林以及少量自然过渡群系映射到具体 Iris 群系。
- 对应的 `*-mask` 定义负责透明区域、越界区域和渐变边界；颜色映射文件记录每种颜色对应的 Iris 群系键。

图片地图只负责活动核心及其过渡带。`terrain-mask` 在距湖岸约 178 格内保持主要影响，随后通过约 155 格的噪声变化平滑淡出，图像边缘的权重为零。因此，活动区不会形成一个方形地形边界。

## 中心湖与湖岸

湖泊中心为 `(0,0)`，水面高度为 Y=50，作者水面约 46,080 格，约等于 180 个区块面积。湖泊的外接范围约为 X=-187～153、Z=-111～118，但外接矩形只是测量范围，实际轮廓由六个旋转湖瓣、连续坐标扰动和深入陆地的湾口共同决定。

湖岸使用二维噪声产生 2～6 格的 hummock/swale 起伏，岸线高度、一阶坡度和周边森林背景连续衔接。湖底使用不同下降尺度和曲率的连续过渡，形成浅坡、浅脊、凹槽和局部平台，避免按距离湖心机械分层。

湖底由三个斑驳森林衍生群系共同提供材质和装饰：

- `dappled/lake`：常规湖底。
- `dappled/lake-rocky`：石头、安山岩和花岗岩斑块。
- `dappled/lake-silt`：黏土、泥巴和砂土斑块。

湖底保留沙砾、泥土、砂、黏土、岩石类材料及水生装饰；三个湖底群系的 `derivative` 和 `vanillaDerivative` 均为 `minecraft:dappled_forest`。湖泊核心不使用河流群系。

## 斑驳森林与外围地形

`dappled` 区域包含核心森林、四种活动森林变体、湖岸、湖底和若干自然过渡群系。湖泊、湖岸和核心森林统一使用原版 `minecraft:dappled_forest` 身份，Iris 键仍用于区分地表对象、树木、颜色和材料。

固定活动种子下，湖泊地表的原版斑驳森林身份为 100%；湖岸外约 150 格的陆地中，斑驳森林身份约占 98.88%。这是一种核心区收敛策略，不会删除包内其他区域或群系定义。核心外仍可自然生成温带、山地、冻原、森林、沼泽、热带、蘑菇、海洋和其他 Iris 幻想群系。

核心外围的背景高度使用八方向参考值和多尺度森林噪声的连续插值：北、东北、东、东南、南、西南、西、西北参考高度分别约为 Y=98、106、84、68、58、63、75、90。该场是连续噪声场，没有八方向硬分区；南侧抬升距离更长，平均坡度更缓。专门制作的东北孤立山脉、山麓和强制山地群系斑块已移除，外围原 Iris 山地仍然可生成。

维度 `landChance` 为 `0.95`。海洋群系、海岸出口和相关原版身份仍保留，只降低其在固定活动种子中的总体出现率。已有山地区域的根群系权重作了轻微提升，没有创建新的 Minecraft 山脉群系。

## 洞穴、地下水文与硫磺洞室

基础洞穴使用 Iris 的三维密度系统：Perlin/Iris 基础密度、Simplex 细节密度、扭曲场、阈值场和垂直边缘淡出共同决定挖空区域。洞穴群系负责洞壁、地板、顶板、装饰、对象和生物环境。斑驳区域允许 rocky、deep、drip、chalk-gardens、moss-pillars 和 sulfur 等洞穴群系。

维度保留随机地表破洞，`caveProfile.allowSurfaceBreak` 为 `true`。自然洞穴、矿物、地下河、海岸洞穴、内陆洞穴和原版深暗区域继续参与生成。

大型 `sulfur-colonnades` 候选间距为 768 格、概率为 0.35，单位面积候选数量约为基础配置的 6.08 倍。另有 `koikoi-core-sulfur-20`，使用 Iris `CENOTE` 地下空间和 `carving/sulfur` 群系，仅允许在 `dappled` 区域内生成，主要范围为 Y=-112～-42，半径约 42 格，高度约 34 格，形状扰动为 0.92，底部包含两格岩浆和硫磺围岩。

固定种子和稳定定义 ID 下，当前核心硫磺洞室锚点约为 `(102,-77,94)`，规划包围范围为 X=58～146、Y=-101～-45、Z=50～138，干燥入口约为 `(115,-77,94)`。该位置是固定活动种子的布局结果；更换世界种子后不能保证洞室仍位于核心湖附近。

## 河流与水文

本包保留 Iris Overworld 的地形优先水文系统。水文规划以 1024 格 tile 组织，分别管理地表河流、地下河、深层流体、海岸洞穴和内陆洞穴。河流路径使用地形感知路由、主尺度与细节尺度蜿蜒、平滑转弯、岸坡侵蚀、瀑布和河口过渡；地下路线可以连接已有洞穴，海岸和内陆 grottos 提供干燥头顶空间。

外围河流可以连接海洋或合法的内陆出口，湖泊核心则由活动图片地图和斑驳湖泊群系控制，不接受河流身份替换。

## 原版结构与活动营地

原版结构继续由 Minecraft/Iris 原生结构系统生成。Overworld 模板中的结构地形适配保留，包括试炼密室高度调整、矿井高度保留、村庄支撑以及部分结构的地形整平。

废弃营地保留原版 18 种营地变体、原版模板、战利品和原版群系身份。当前使用 119 条群系级 `nativeStructures` 规则，每区块独立采样，密度为 `5/361`；原版 `minecraft:abandoned_camp` 结构集的固定 `RANDOM_SPREAD` 通道已禁用，因此营地不会形成固定的 9 区块方格。其他结构的原版间距、群系限制和 locate 行为保持不变。

## 兼容性与开发参考

核心相关群系尽量复用原版身份：斑驳森林湖泊、湖岸和森林均使用 `minecraft:dappled_forest` 作为 `vanillaDerivative`。这些定义没有 `customDerivitives`，因此不会单独产生 `iris.biome.koikoi/dappled_*` 客户端翻译键。

Iris 通过 `customDerivitives` 向 Minecraft 注册自定义群系。Koikoi 当前有 145 个客户端翻译键，格式为 `iris.biome.koikoi/<customBiomeId>`；资源包可在 `assets/iris/lang/zh_cn.json` 中覆盖这些键，例如：

```json
{
  "iris.biome.koikoi/tropical_plains": "热带平原"
}
```

当前 Iris 生成的实际 Minecraft 群系资源使用 `iris:biomes/<sha256>` 内容寻址键。完整的翻译键、源定义和实际注册资源见 [Iris 自定义群系注册键名表](群系键名列表.md)，机器可读版本见 [biome-keys.json](biome-keys.json)。若 datapack 需要匹配原版身份，应使用 `vanillaDerivative` 或 Minecraft 群系标签；若需要匹配 Iris 自定义注册资源，应使用注册表中的 `iris:biomes/<sha256>`。
